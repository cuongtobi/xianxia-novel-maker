## Function boundaries

Use the closest dominant function rather than loading adjacent examples together by default.

- `CAL-DIAL-01` = bargaining, suspicion, status-aware interpersonal pressure.
- `CAL-REL-01` = affection, family bond, vulnerability, personal stakes.
- `CAL-WORLD-01` = an event causes wider environmental/world consequences.
- `CAL-POL-01` = actors deliberately make faction/resource decisions that trigger reactions.
- `CAL-TACT-01` = immediate survival or tactical choice.
- `CAL-QUIET-01` = ordinary rhythm, training, rest, travel, companionship.

## Selection rule

Normally load **one primary example**. Add a second only when the scene genuinely combines two functions. Use three only for a long mixed-mode chapter.

Do not load all examples by default.

## Takeover

Priority after a story develops:

1. user-approved project final matching the current function;
2. strong project-owned example;
3. calibrated original example from this folder;
4. generic framework bootstrap example.

Project-owned examples should gradually replace calibration examples without changing the state-driven architecture.
