## Selection rule

Normally load **one primary example**. Add a second only when the scene genuinely combines two functions. Use three only for a long mixed-mode chapter.

Do not load all examples by default.

## Takeover

Priority after a story develops:

1. user-approved project final matching the current function;
2. strong project-owned example;
3. calibrated original example from this folder;
4. generic framework bootstrap example.

Project-owned examples should gradually replace calibration examples without changing the state-driven architecture.
