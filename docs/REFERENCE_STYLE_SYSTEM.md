# Reference Style System

Reference Style là lớp hỗ trợ **high-level house style**, không phải controller sáng tác và không phải lệnh bắt chước tác giả/tác phẩm.

## 1. Hierarchy

`Reference Profile → Story Style Bible adaptation → Writer → project-owned calibration → Style Fingerprint QC`.

Direct writing source luôn là `bible/style_bible.md`.

## 2. Allowed adaptation

Có thể học ở mức cao:

- prose density/rhythm;
- mức trực diện vs trữ tình;
- POV distance;
- cách xử lý cultivation/combat/exposition;
- emotional restraint/rupture;
- world-scale reveal;
- diction balance.

Không copy:

- câu/cụm;
- rhetorical frame dễ nhận diện;
- plot/scene beat;
- character/world identity;
- convert syntax;
- stock gesture của nguồn.

## 3. Default profile

Nếu story bật default profile:

`docs/reference_profiles/TIEN_NGHICH_HIGH_LEVEL_STYLE.md`

Style Director phải adapt theo premise và Character DNA, không dùng profile như few-shot prose.

## 4. Weakness filter

Không học các nhược điểm như exposition/recap dài, cú pháp dịch cứng, stock gesture, connector lặp, slow transition không có giá trị hoặc aphorism thiếu scene support.

## 5. Project-owned calibration

Chỉ dùng final/user-approved samples của chính story. Không khóa calibration quá sớm.

Sample set nên đa dạng theo **scene type** như narration, dialogue, action, cultivation/craft, quiet/emotional, combat/wonder nếu story có; không yêu cầu Narrative Engine quota.

Mỗi chapter chỉ cần vài sample phù hợp. Học rhythm/diction/POV texture, không copy câu/rhetorical frame.

## 6. Style QC

Style Fingerprint Auditor bắt:

- drift-away khỏi house style;
- overfit/imitation;
- weakness leakage;
- AI-like repeated cadence/rhetorical tics.

Reference Style không tạo thêm gate/controller ngoài Style Auditor hiện hữu.
