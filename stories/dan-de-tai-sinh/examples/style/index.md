# Style Example Bank — Đan Đế Tái Sinh — v4.0

> Examples calibrate prose function only; they never define plot, character or scene shape.

# Framework Calibration

- Profile: `examples/calibration/PROFILE.md`
- Calibrated originals: `examples/calibration/index.md`
- Raw external samples are not loaded into Writer.

# Selection Rules

- Default: one primary example per scene.
- Add a second only for genuinely mixed function; max three for a long mixed-mode chapter.
- Select by function, tempo, POV distance and dialogue/action/exposition balance.
- Never select because the framework example’s plot resembles the target scene.
- Priority: user-approved project final > project-owned curated > calibrated original > generic bootstrap.
- Never copy wording, imagery, rhetorical frames, paragraph sequence or scene shape.
